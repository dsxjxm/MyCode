# 局域网仿真实训教学平台

浏览器/服务器（B/S）架构的局域网仿真实训教学平台，面向职业院校课堂实训。

技术栈：**Node.js + Express + SQLite（sql.js WASM，零原生依赖）+ 原生前端**，无构建步骤、离线可用，`npm start` 一键启动。

已上线四个实训模块：

| 模块 | 内容 |
| --- | --- |
| WWW / IIS 站点 | 文件空间管理、分屏代码编辑器、实时预览、站点设置（默认文档、MIME、访问日志）、HTML/CSS/JS 语法速查悬浮面板（可拖拽/收起、搜索、一键插入） |
| FTP / Telnet 终端 | 命令行模拟、目录浏览、上传下载、FTP 账号与空间管理 |
| DNS / DHCP 网络模拟 | SVG 拓扑画布、PC 拖放、DHCP 地址池分配、DNS 记录解析、ipconfig/ping/nslookup/tracert/arp/netsh 命令模拟 |
| 邮件服务器 SMTP / POP3 | 邮箱注册（别名、图形验证码、模拟短信）、密码/短信登录、收发邮件、附件、富文本、通讯簿、黑名单、定时发送、SMTP/POP3 协议日志 |

## 二、本地部署流程

### 1. 解压

把压缩包解压到任意目录，例如 `D:\lan-sim\`。

### 2. 安装依赖

在该目录打开终端（Windows：文件夹地址栏输入 `cmd` 回车）：

```bash
npm install
```

> 首次安装需联网。若网络较慢，可先执行
> `npm config set registry https://registry.npmmirror.com` 再安装。

### 3. 启动

```bash
npm start
```

看到如下输出即启动成功：

```
局域网仿真实训教学平台 已启动
本机访问：http://localhost:3000
局域网访问：http://192.168.x.x:3000
教师初始账号：admin / admin123
```

浏览器打开 <http://localhost:3000>，自动进入登录页。

### 4. 停止

在运行终端按 `Ctrl + C`。

```
├── test/                # 单元测试（npm test）
├── data/                # 运行时数据（自动生成，勿删）
└── package.json
```

### 数据保存位置

- 默认：项目下的 `data/` 目录（`platform.db`、学生文件空间、邮件附件等）
- 如该目录不可写，自动回退到系统临时目录 `lan-sim-data`
- 也可自定义：

```bash
# Windows
set DATA_DIR=D:\lan-sim-data && npm start

# macOS / Linux
DATA_DIR=/opt/lan-sim-data npm start
```

> 删除 `data/` 相当于重置平台（演示数据会在下次启动时重新生成）。

## 七、常见问题

**1. 端口被占用**
换端口启动：`PORT=8080 npm start`（Windows 用 `set PORT=8080 && npm start`）。

**2. 启动报 Cannot find module**
未安装依赖或安装不完整，重新执行 `npm install`。

**3. 数据想恢复初始状态**
停止服务，删除 `data/` 目录后重新 `npm start`。

**4. 学生邮件验证码在哪里看**
点击「获取验证码」后，页面右下角会弹出模拟手机短信，显示 6 位验证码，可点「一键填入」。

**5. 教师如何关闭学生编辑网络配置**
教师控制台 →「模块管理」→ 网络模拟卡片中的开关「允许学生编辑 DHCP / DNS / PC 配置」。

## 八、Windows 7 / 8 离线版（免安装 Node）

Windows 7 无法运行 Node 14 及以上版本（会报 `无法定位程序输入点 GetHostNameW`）。为此单独提供了离线版压缩包：

- **Win7 离线版**：内置 Node 12.22.12 的 64 位与 32 位运行环境（`node-x64.exe` / `node-x86.exe`），`启动.bat` 按系统架构自动选择
- **Win8 离线版**：内置 Node 14.21.3 的 64 位与 32 位运行环境，其余用法相同
- 后端已用 esbuild 打包为单个 `dist\server\server.cjs`，无需 npm install、无需联网
- 要求：Windows 7 **SP1** / Windows 8 / 8.1；建议装齐补丁，至少 KB2999226（UCRT）、KB4474419 / KB4490628（SHA-2）
- 浏览器：Chrome / Edge 最高 109 版（Win7、Win8.1），或 360 极速浏览器、Firefox 115 ESR
- 使用：解压后双击 `启动.bat`，访问 `http://localhost:3000`；数据保存在 `data\`（由启动脚本指定 `DATA_DIR`）
- `sql.js` 固定为 `1.12.0`（1.13 及以上的 wasm 在 Node 12 下会报 `wasm function signature contains illegal type`）

## 九、并发与性能（60 人班级）

软件侧的三个瓶颈已针对性优化：

1. **登录密码校验改为异步**：`verifyPasswordAsync` 用 `crypto.scrypt` 回调版走 libuv 线程池，多人同时登录不再串行卡住事件循环；`UV_THREADPOOL_SIZE=8`（启动脚本已设置）
2. **数据库落盘改为合并写**：sql.js 是内存库，原先每次写都整库导出并覆盖文件；现在 250ms 内的多次写合并为一次落盘（退出/中断前强制 flush，最多丢 250ms 写入），并发写不再互相排队
3. **HTTP 长连接调优**：`keepAliveTimeout=65s`、`headersTimeout=66s`，避免局域网浏览器复用连接时出现 `ECONNRESET`
4. **登录限流排队**：同一时刻的密码校验并发超过阈值（默认 6，可用 `LOGIN_MAX_CONCURRENT` 调整）时，服务端立即返回 `202` 并给出建议重试间隔，登录页显示“请稍候”并自动重试，避免瞬时登录把线程池打满

压测脚本：`scripts/loadtest.mjs`（零依赖，兼容 Node 12+）

```bash
node scripts/loadtest.mjs --base http://127.0.0.1:3000 \
  --accounts 20250101,20250102,20250103 \
  --stages 20:30,40:30,60:30 --think 1000-2500 --write 30
```

参数：`--stages 并发:秒`、`--think 最小-最大毫秒`、`--write 写占比%`、`--pid`/`--db`（Linux 下统计内存与库大小）。

建议课堂开场分批登录（30+30，间隔 1~2 分钟）；Windows 上把程序目录与 `data` 加入 Defender 排除项、关闭磁盘索引、用 SSD，可明显降低写库与文件操作延迟。

## 十、运行监控与学期归档（v0.3.0）

教师控制台左侧新增两个入口，均需教师身份：

### 运行监控

- **在线人数**：近 3 分钟内有请求活动的教师 / 学生数量，并列出用户与最近活动时间
- **负载**：进程内存、CPU 使用率、系统 1/5/15 分钟负载、运行时长、数据库文件大小
- **请求质量**：近 60 秒每秒请求数、平均 / P95 / P99 延迟、5xx 错误数
- **慢请求**：耗时 ≥ 500ms 的请求（方法、路径、耗时、状态、用户），可据此定位卡顿接口
- **登录排队**：当前排队人数、并发上限与累计限流次数

默认每 3 秒自动刷新，可暂停或手动刷新；数据来自进程内统计接口 `GET /api/admin/metrics`，不依赖外部监控组件。

面板下方另有「环境自检与自动配置」：启动时读取 CPU 型号 / 核心数 / 内存，并用与登录一致的 scrypt 参数做一次微基准，自动选择**低配 / 标准 / 高性能**档位，决定登录并发上限、线程池大小、写盘防抖与慢请求阈值。启动日志会打印检测结果，监控面板可随时查看。全部参数都可用环境变量显式覆盖：`LOGIN_MAX_CONCURRENT`、`UV_THREADPOOL_SIZE`、`DB_PERSIST_DEBOUNCE_MS`、`METRICS_SLOW_MS`。

### 学期归档

- 一键把当前内存数据库落盘并复制为 `data/archives/archive-<时间>-<学期>.db` 快照
- 可选「归档后清理邮件」（清空收件/发件/草稿/定时任务与附件）与「清空回收站」
- 归档先于清理执行，因此归档文件始终包含清理前的完整数据
- 列表中可直接下载或删除归档文件

> 归档接口：`GET/POST /api/admin/archives`、`GET /api/admin/archives/:name/download`、`DELETE /api/admin/archives/:name`

### 上传文件类型限制（v0.4.0）

教师控制台「模块管理」页底部可设置允许上传的扩展名（逗号 / 空格分隔，不带点），留空表示不限制：

- 作用于三个上传入口：WWW 站点文件上传、FTP `put` 上传、邮件附件
- 服务端强制校验文件名后缀，非法类型返回 400 并提示具体原因；限制开启时无扩展名文件同样拒绝
- 学生端文件选择框自动设置 `accept` 属性作为前端提示
- 说明：仅按文件名后缀判断，学生把病毒文件改成允许的扩展名无法从技术上完全拦截，建议同时开启杀毒软件
