# 局域网仿真实训教学平台

C/S（浏览器/Web）架构的局域网仿真实训教学平台，当前已完成 **WWW 实训模块**（分屏编辑器 + 实时预览 + IIS 式站点设置），后续将陆续加入 FTP/Telnet、DNS/DHCP 等模拟模块。

技术栈：Node.js + Express + SQLite（`node:sqlite` 内置）+ 原生前端，无需构建步骤，离线可用。

---

## 一、本地环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows / macOS / Linux 均可 |
| Node.js | **>= 24.0.0**（必须，使用了内置 `node:sqlite`） |
| 浏览器 | Chrome / Edge / Firefox 最新版 |

> 查看版本：`node -v`。若版本不足，请到 <https://nodejs.org/> 下载 LTS 或 Current 版本（24+）安装。

---

## 二、本地运行步骤（3 步）

### 1. 解压并安装依赖

把下载的压缩包解压到任意目录，然后在该目录打开终端（Windows 可在文件夹地址栏输入 `cmd` 回车）：

```bash
npm install
```

### 2. 启动服务

```bash
npm start
```

看到类似下面的输出就表示启动成功：

```
局域网仿真教学平台已启动
  本地访问:   http://localhost:3000
  局域网访问: http://192.168.x.x:3000
```

### 3. 打开浏览器

访问 <http://localhost:3000> ，会自动跳转到登录页。

**首次运行只有教师账号**：`admin / admin123`。登录后可在「学生账户」里手动建班级、建学生。

如果想**开箱即有演示数据**（1 个班级 + 3 名学生），另开一个终端执行：

```bash
node scripts/seed-demo.mjs
```

然后用学生账号登录：`20250101 / 123456`（另有 20250102、20250103，密码相同）。

> 停止服务：在运行 `npm start` 的终端按 `Ctrl + C`。

## 四、目录说明

```
.
├── server/            # 后端（Express + SQLite）
│   ├── index.js       # 入口
│   ├── db.js          # 数据库初始化（首次运行自动建表、建 admin 账号）
│   ├── storage.js     # 学生文件空间管理
│   └── routes/        # 各业务接口
├── public/            # 前端静态页面（登录页、教师控制台、学生工作台）
├── scripts/
│   └── seed-demo.mjs  # 演示数据种子（可选）
├── test/              # 单元测试，`npm test` 运行
└── data/              # 运行时数据（首次运行自动生成），包含：
    ├── platform.db    # SQLite 数据库
    └── classes/       # 每个学生的个人空间（www / ftp / homework / design）
```

> `data/` 是运行时生成的，**不要删**；删掉会清空所有班级、学生和文件（相当于重置）。

---

## 五、局域网内让学生访问

启动时控制台会打印「局域网访问」地址（如 `http://192.168.1.100:3000`），同一局域网的学生在浏览器输入该地址即可。若学生打不开，检查教师电脑防火墙是否放行了 3000 端口。

- 修改端口：`set PORT=8080 && npm start`（Windows）或 `PORT=8080 npm start`（mac/Linux）。
