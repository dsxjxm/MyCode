使用说明

本学期首期功能：账户体系 + WWW（IIS 模拟）实训。

一、快速开始

  1. 在“班级管理”中创建班级。
  2. 在“学生账户”中逐个添加，或点击“导入名单”批量导入；建议先下载导入模板。
  3. 学生用学号（或自定义账号）和初始密码登录，进入 WWW 实训工作台。
  4. 在“概览”中查看平台统计，并向全体或指定班级发布教学通知，通知会显示在学生工作台顶部。

二、学生空间目录

每个学生自动生成独立目录，包含四个子目录：

  • www/：WWW 站点根目录，工作台编辑与预览的内容都在这里；
  • ftp/：FTP 实训空间（后续模块使用）；
  • homework/：作业提交目录（后续模块使用）；
  • design/：个人设计作品目录。

三、导入名单格式

支持 .xlsx / .csv，表头需包含“学号”“姓名”，“账号”“密码”列可选。未填写账号时默认学号作为账号，未填写密码时使用导入窗口中的初始密码。

四、账号与数据安全

删除学生或班级时，对应文件目录不会真正删除，而是移入数据目录下的 _trash/ 回收站，可按时间找回。预览页面运行在浏览器沙箱中，学生代码无法读取平台登录信息。教师可在页面右上角修改自己的登录密码。

五、学生工作台

文件树支持新建、上传、重命名、下载与删除；站点设置中可调整默认文档顺序、MIME 类型，并查看最近访问日志；编辑器底部可调整字号，拖动中间分隔条可调整分栏宽度，双击恢复。

六、已上线的实训模块

平台目前包含四个模块：WWW（IIS 站点模拟）、FTP / Telnet 终端、DNS / DHCP 网络模拟、邮件服务器（SMTP / POP3）。教师可在左侧「模块管理」进入各模块；其中网络模拟与邮件服务器提供教师管理界面，可配置 DHCP、DNS、邮箱账号、黑名单与定时发送等。
